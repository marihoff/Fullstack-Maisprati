// Aula 16 - Introdução ao Desenvolvimento Web: História, Tecnologias e o Papel do Frontend // links importantes // https://www.youtube.com/watch?v=TNQsmPf24go // https://www.geeksforgeeks.org/blogs/how-does-the-internet-work/ // principais tenologias do desenvolvimento web // HTML - HyperText Markup Language: é a linguagem de marcação usada para criar a estrutura e o conteúdo de uma página web. Ele define os elementos da página, como títulos, parágrafos, links, imagens e outros componentes visuais. // CSS - Cascading Style Sheets: é a linguagem de estilo usada para controlar a aparência visual de uma página web. Ele permite que os desenvolvedores definam cores, fontes, layouts e outros aspectos visuais para tornar a página mais atraente e fácil de usar. // JavaScript: é uma linguagem de programação usada para adicionar interatividade e dinamismo a uma página web. Ele permite que os desenvolvedores criem funcionalidades como animações, validação de formulários, manipulação de eventos e muito mais. // O papel do frontend no desenvolvimento web é criar a interface do usuário e garantir que a experiência do usuário seja agradável e intuitiva. O frontend é responsável por transformar o design visual em código funcional, garantindo que a página seja responsiva, acessível e compatível com diferentes dispositivos e navegadores. Ele também trabalha em conjunto com o backend para garantir que os dados sejam exibidos corretamente e que as funcionalidades sejam implementadas de forma eficiente. Document
