// Aula 24 - Introdução ao JavaScript: Conceitos e Uso no Frontend Manipulando DOM DOM = Document Object Model, é uma interface de programação para documentos HTML e XML. Ele representa a página para que programas possam alterar a estrutura do documento, estilo e conteúdo. O DOM fornece uma representação estruturada do documento como uma árvore de nós e objetos; dessa forma, os desenvolvedores podem manipular o conteúdo, estrutura e estilo da página web. representação da página de html como uma árvore de nós, onde cada nó representa uma parte do documento, como elementos, atributos e texto. Isso permite que os desenvolvedores acessem e modifiquem facilmente o conteúdo e a estrutura da página usando linguagens de programação, como JavaScript.
